---
description: 指定したノートに繋がる既存ノートを探してリンクを張る
argument-hint: "<ノート名またはパス>"
---

`$ARGUMENTS` で指定されたノートの孤立を解消する。

1. 対象ノートを特定する。パスでなければ `rg -l` / `find` でファイル名から探す。
   複数該当したら候補を出して確認する。
2. 対象ノートを全文読む。
3. 本文から検索語を3〜5個抽出する（タイトルの語だけでは足りない。
   本文中の概念語・固有名詞・言い換えを含める）。
4. Vault 全体を検索し、関連候補を集める。
   ```
   rg -il "<語1>|<語2>|<語3>" --glob '*.md'
   ```
5. 候補それぞれについて、対象ノートとの関係を次から判定する。
   - **前提になる** / **補強する** / **対立する** / **具体例である** / **一般化である**
   関係が言語化できない候補は捨てる。「なんとなく近い」はリンクしない。
6. 上位3〜5件を提案し、承認を得る。
7. 承認後:
   - 対象ノートの `## 関連` に `[[リンク]] — <関係>` を追記する。
   - **リンク先のノートの `## 関連` にも逆リンクを追記する**（双方向にする）。
   - 両ノートの `updated` を今日の日付に更新する。
8. 関連候補が1件も無ければ、「孤立ノート」であることを伝え、
   このノートを繋ぐには何を書く必要があるかを1〜2行で提案する。
