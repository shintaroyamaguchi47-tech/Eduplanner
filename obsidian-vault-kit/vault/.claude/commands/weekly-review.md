---
description: 直近1週間を振り返り、育てるべきノートを挙げる
---

週次レビューを行う。**新しいノートを作るのではなく、既にあるものを見直す**のが目的。

1. `date +%Y-%m-%d` で今日を取得し、直近7日の範囲を確定する。
2. その期間に触られたノートを集める。
   ```
   find . -name '*.md' -mtime -7 -not -path './.git/*' -not -path './99_Templates/*'
   ```
3. 次の5点を**簡潔に**報告する。長文にしない。

   **① 今週書いたもの**
   フォルダ別の件数と、特筆すべきノート2〜3本。

   **② デイリーに埋もれている種**
   `10_Daily/` の今週分から、永久ノートに昇格する価値のある記述を最大3つ抜き出す。
   ノート名の案と、なぜ昇格に値するかを1行ずつ。

   **③ 孤立ノート**
   今週作られたノートのうち `## 関連` が空、またはリンクが0本のもの。
   ```
   rg -L "\[\[" --glob '*.md' <今週のファイル群>
   ```

   **④ 停滞している `status: seed`**
   `rg -l "status: seed" 30_Permanent/` のうち、`updated` が30日以上前のもの。
   育てるか `90_Archive/` へ送るかを問う。

   **⑤ 今週の一言**
   今週のノート群から読み取れる関心の方向を、1〜2文で言い当てる。
   Vault に書かれていることだけを根拠にする。

4. 最後に「次の一手」を**1つだけ**提案する。複数出さない。
   例:「`②` の1本目を `/link` で繋ぐのが今週いちばん効きます」

ファイルの作成・移動・書き換えはこのコマンドでは行わない。提案までで止める。
