# ノート取り込み

断片を「後から検索でき、後からリンクできる」形にして Vault に着地させる。
要約することが目的ではない。**未来の自分が再利用できる状態にすること**が目的。

## 手順

1. **種類を判定する**

   | 入力 | type | 置き場所 |
   |---|---|---|
   | 本・論文・動画・研修の内容 | `literature` | `20_Literature/` |
   | 自分の思いつき・違和感 | `fleeting` | `00_Inbox/` |
   | 会議・打ち合わせの記録 | `fleeting` | `00_Inbox/`（タイトルに `議事録` を含める） |
   | 授業をやってみた記録 | `lesson` | `10_Daily/` に追記（`lesson-log` スキルを使う） |
   | 判断がつかない | `fleeting` | `00_Inbox/` |

   迷ったら `00_Inbox/`。永久ノート（`30_Permanent/`）へは、この
   スキルからは**直接置かない**。昇格は `zettel-refine` の仕事。

2. **既存ノートを確認する**

   ```
   rg -il "<入力の主要キーワード>" --glob '*.md'
   ```

   同じ話題のノートが既にあれば、新規作成せず追記を提案する。
   その際は既存ノートの `updated` を今日の日付に更新する。

3. **個人情報を落とす**

   生徒名・保護者名・住所・個票の点数が含まれていたら、保存前に
   「生徒A」「保護者A」などへ置換する。置換したことを応答で伝える。

4. **ノートを書く**

   - フロントマターは Vault の `CLAUDE.md` の規約に従う。
   - `literature` のときは `source` を必ず埋める。
     出典が分からない場合は保存せず、先に出典を尋ねる。
   - 本文の構成:

     ```markdown
     ## 要点
     - 箇条書き3〜5行。原文の言葉ではなく自分の言葉に直す。

     ## 引用
     > 原文をそのまま。ページ・時刻を添える。

     ## 自分の実践への接続
     これが授業・校務のどこに効くかを1段落。ここが後で永久ノートになる。

     ## 関連
     - [[既存ノート]] — なぜ関連するかを1行
     ```

   - `literature` 以外では `## 引用` を省略してよい。
     `## 自分の実践への接続` は**省略しない**。書くことが無ければ
     「現時点では接続先が見えていない」と明記する。

5. **リンクを張る**

   手順2で見つけた既存ノートを `## 関連` に入れる。
   1つも無ければ、その旨を本文に書き、応答でも「孤立ノートになった」と伝える。

6. **報告する**

   保存先のパスと、張ったリンクを列挙する。ノート全文の再掲はしない。

## やらないこと

- 1回の依頼で4つ以上の新規ノートを作らない。多い場合は一覧を出して確認する。
- 既存ノートの本文を書き換えない（追記のみ）。
- 出典不明のものを `20_Literature/` に置かない。
