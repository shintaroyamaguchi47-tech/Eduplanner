# MOC（地図ノート）の作成・更新

MOC はリンク集ではない。**「このテーマをどう考えているか」の目次**である。
リンクの羅列で終わったら失敗。並び順と一言解説に思考が出る。

## 手順

1. **範囲を確定する**

   テーマが広すぎると MOC が使い物にならない。
   `社会科 MOC` は広すぎる。`社会科の問いづくり MOC` くらいまで絞る。
   広いテーマを求められたら、下位 MOC への分割を提案する。

2. **材料を集める**

   ```
   rg -il "<テーマ語1>|<テーマ語2>" --glob '*.md'
   ```

   `30_Permanent/` を主軸に、`20_Literature/` と `50_Projects/` から補う。
   `00_Inbox/` は含めない（未整理のものを地図に載せない）。

   集まったノートが**3つ未満なら MOC を作らない**。まだ地図にする段階ではないと伝える。

3. **並べる順を決める**

   五十音順やファイル順で並べない。次のどれかの軸で並べる。

   - **議論の順**: 前提 → 主張 → 反論 → 実践
   - **時間の順**: 単元計画 → 授業中 → 評価 → 振り返り
   - **抽象度の順**: 原理 → 方法 → 具体的な教材

   どの軸を選んだかを MOC の冒頭に書く。

4. **書く**

   ```markdown
   ---
   title: <テーマ> MOC
   created: 2026-08-29
   updated: 2026-08-29
   type: moc
   tags: []
   status: growing
   ---

   ## このノートは
   <テーマ>について自分が考えてきたことの入口。<選んだ軸>の順に並べている。

   ## 現時点の立場
   このテーマについて今どう考えているかを3行以内で。MOC の中で最も重要な部分。
   ノート群を読んだ上での総合。

   ## 前提
   - [[ノートA]] — なぜ前提なのかを1行

   ## 主張
   - [[ノートB]] — 何を言っているかを1行

   ## 反論・未解決
   - [[ノートC]] — どこが引っかかっているか

   ## 空白
   - まだ考えていない論点を箇条書き。ここが次に書くノートの候補になる。

   ## 関連 MOC
   - [[別のMOC]]
   ```

5. **更新のとき**

   既存 MOC を更新する場合は、リンクの追加と `## 現時点の立場` の見直しを行う。
   **`## 空白` は消さずに育てる。** 埋まった項目は打ち消し線ではなく削除し、
   代わりに該当ノートへのリンクを本文に足す。

6. **各ノートから MOC へ逆リンクを張る**

   MOC に載せたノートの `## 関連` に `[[<テーマ> MOC]]` を1行追記する。

## やらないこと

- ノート3つ未満で MOC を作らない。
- 一言解説の無いリンクを並べない。
- `00_Inbox/` のノートを載せない。
