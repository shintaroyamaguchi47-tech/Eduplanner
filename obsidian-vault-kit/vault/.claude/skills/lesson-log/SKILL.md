# 授業記録

授業記録の価値は「やったこと」ではなく「**次に何を変えるか**」にある。
指導案の再掲は不要。変数と結果を残す。

## 個人情報の扱い（必須）

生徒の発言や様子を記録するときは、**必ず匿名化する**。

- 実名 → 「生徒A」「Bさん」
- 特定につながる記述（部活・家庭状況・診断名・座席）は書かない
- 個票の点数は書かない。書くのは分布や傾向のみ（例: 「約3割が未記入」）

匿名化したことは応答で伝える。判断に迷ったら保存せず確認する。

## 手順

1. **記録先を決める**

   その日の `10_Daily/YYYY-MM-DD.md` に `## 授業記録` セクションとして追記する。
   デイリーノートが無ければ作る。

   単元全体の振り返りなら `50_Projects/<単元名>.md` に追記する。

2. **書く**

   ```markdown
   ## 授業記録: <学年><教科> <単元名> 第<n>時

   - **ねらい**: 本時で生徒に何ができるようになってほしかったか（1行）
   - **打ち手**: 実際に使った発問・資料・活動形態。ここが再現したい「変数」
   - **結果**: 生徒がどう動いたか。観察できた事実を書く（解釈と分けて）
   - **解釈**: なぜそうなったと考えるか
   - **次にやるなら**: 次年度・次クラスで変える点を具体的に1〜3個

   ### 使った資料
   - [[教材ノートへのリンク]] / ファイル名

   ### 関連
   - [[関連する永久ノート]] — なぜ関連するか
   ```

   - **「結果」と「解釈」を必ず分ける。** 「盛り上がった」は解釈、
     「挙手が普段2〜3人のところ10人以上」が事実。
   - 「次にやるなら」が書けない記録は価値が半減する。何も無ければ
     「変更点なし。この形で再現する」と明記する。

3. **既存の実践知とつなぐ**

   ```
   rg -il "<単元名>|<扱った概念>|<使った活動形態>" 30_Permanent/ 50_Projects/
   ```

   過去に同じ単元・同じ手法をやっていれば、その記録を読んで**比較する**。
   「去年は○○だったが今年は△△だった」の一文があると、記録が資産になる。

4. **昇格を判断する**

   その授業から、単元を超えて言える一般的な知見が出たら、
   永久ノート化を**提案する**（勝手には作らない）。

   - 昇格すべき例:「資料を2つ与えると比較が始まるが3つだと止まる」
   - 昇格すべきでない例:「今日は導入の時間配分をミスった」（その日の話）

   提案が受け入れられたら `zettel-refine` スキルに沿って `30_Permanent/` に書く。

5. **報告する**

   追記したファイルのパス、匿名化した箇所の有無、永久ノート化の提案を伝える。

## やらないこと

- 指導案をそのまま貼らない。記録は指導案の写しではない。
- 生徒の実名・個票を書かない。例外は無い。
- うまくいかなかった授業を美化しない。失敗の記録の方が翌年効く。
