# 毎朝の自動バックアップ（Google ドライブ）

Firebase にある EduPlanner の全データを、毎朝6時ごろに Google ドライブの「EduPlanner バックアップ」フォルダへ保存する Google Apps Script です。スマホやパソコンでアプリを開いていなくても動きます。

- 1つのファイルに、その朝の時点の**全データ**（全年度の週案・テンプレート・年間行事・ToDo・ノート・単元計画・メモ・資料）が入ります
- ファイル名は `EduPlanner_2026-11-05.json` のように日付になります
- **毎日のファイルは30日分**残します。それより古いものは、**各月の最初のファイルだけ残して**ゴミ箱へ移します（ゴミ箱からはさらに30日間取り戻せます）
- 保存したファイルは、アプリの 設定 → データバックアップ →「データを復元（インポート）」でそのまま読み込めます

## はじめての設定（1回だけ・10分ほど）

**Firebase プロジェクト（eduplanner-v2）を作った Google アカウント**で行ってください。別のアカウントだと権限がなく、データを読めません。

1. パソコンで https://script.google.com を開き、左上の「新しいプロジェクト」を押す
2. 左上の「無題のプロジェクト」を押して、名前を「EduPlanner 自動バックアップ」にする
3. 左側の ⚙（プロジェクトの設定）を押し、「『appsscript.json』マニフェスト ファイルをエディタで表示する」にチェックを入れる
4. 左側の `<>`（エディタ）に戻り、ファイル一覧の `appsscript.json` を開く。中身を全部消して、このフォルダの [`appsscript.json`](appsscript.json) の中身を貼り付ける
5. ファイル一覧の `コード.gs` を開く。中身を全部消して、このフォルダの [`Code.js`](Code.js) の中身を貼り付ける
6. 💾（保存）を押す
7. 上の関数の選択欄で `setup` を選び、「▷ 実行」を押す
8. 「承認が必要です」→「権限を確認」→ 自分のアカウントを選ぶ
   - 「Google はこのアプリを確認していません」と出たら、「詳細」→「EduPlanner 自動バックアップ（安全ではないページ）に移動」を押す。自分で作ったスクリプトなので問題ありません
   - 許可の一覧に「Google ドライブのすべてのファイルの表示、編集…」が出ます。保存先のフォルダを作って古いファイルを整理するために必要です。このスクリプトが触るのは「EduPlanner バックアップ」フォルダだけです
   - 「許可」を押す
9. 下の実行ログに「保存しました」「毎朝 6 時ごろの自動バックアップを登録しました」と出れば完了です。Google ドライブに「EduPlanner バックアップ」フォルダができ、今日のファイルが入っています

GitHub からコピーするときは、ファイルを開いて右上の「Raw」を押すか、コピーのボタン（📋）を使うと貼り付けやすいです。

## ふだんのこと

- やることは特にありません。毎朝自動で保存されます
- 失敗したときは、Google から「Apps Script」の失敗のお知らせメールが届きます
- 復元するとき: ドライブの「EduPlanner バックアップ」から戻したい日のファイルをダウンロード → アプリの 設定 →「データを復元（インポート）」で選ぶ（今のデータは上書きされます）

## 困ったとき

| 出たメッセージ | どうする |
|---|---|
| Firestore を読む権限がありません | Firebase プロジェクトを作ったのと同じ Google アカウントでスクリプトを作り直す |
| ユーザーが ○ 人見つかりました | `Code.js` の先頭の `UID: ''` に、自分のユーザー UID を入れる（Firebase コンソール → Authentication → ユーザー の「ユーザー UID」） |
| データが見つかりませんでした | `UID` が正しいか確認する |

## 設定を変えるとき

`Code.js` の先頭の `CONFIG` を書き換えて保存します。

- `KEEP_DAYS`: 毎日のファイルを残す日数（初期値 30）
- `HOUR`: 実行する時刻（初期値 6）。変えたら、もう一度 `setup` を実行する
- `FOLDER_NAME`: 保存先のフォルダ名

自動バックアップをやめるときは、関数 `stopDailyBackup` を選んで実行します（保存済みのファイルは消えません）。

## 注意

保存先は Firebase と**同じ Google アカウントのドライブ**です。障害や誤操作でデータが消えたときの備えにはなりますが、Google アカウント自体に入れなくなったときには使えません。ときどき（月に1回など）、アプリの書き出しファイルをパソコンや別のアカウントにも保存しておくと安心です。
